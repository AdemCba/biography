# Step 5: revise after the quality gate

The article below failed {{SITE_NAME}}'s quality gate. Fix it so it passes, without lowering its
accuracy.

You get: the style guide, `person.json`, the article, and the list of problems the checker found.

- Fix every ERROR. Fix the warnings that are about style or substance.
- Thin content: add substance, not words. Open the existing sources (and search for new reliable ones)
  for facts the article does not use yet: dates, results, decisions, quotes, context. Every new fact
  gets a citation. If the sources simply do not support a fuller article, say so in `note` instead of
  padding.
- AI-sounding style: rewrite the flagged passages in plain, concrete language with varied sentences.
  Remove cliché phrases entirely rather than swapping in synonyms.
- Near-duplicate: restructure and rewrite the overlapping passages from this person's own facts.
- Keep what is already good. Do not change facts that are correctly sourced.
- New sources must be real pages you opened; give id, url, title, publisher, type, accessed (today).
- Never invent facts, quotes, sources or URLs.
- When the fact-check rejected the article, fix each finding it lists: add the missing body citation,
  reword or drop the unsupported claim, correct the wrong one. Citation tags go in the body only; the
  frontmatter fields (summary, knownFor, metaDescription, FAQ) must not contain `[s:...]` tags.
